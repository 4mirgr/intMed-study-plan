# راه‌اندازی یک‌بارهٔ DeepSeek

دو چت جدا بساز. تاریخچه‌شان را قاطی نکن.

## چت ۱ — نام: IntMed Coordinator

اولین پیام را عیناً بفرست:

```text
تو هماهنگ‌کنندهٔ پروژه IntMed هستی، نه برنامه‌نویس آن.
قرارداد: docs/ai/COORDINATOR.md و صف: docs/ai/QUEUE.md
قواعد:
- کد محصول، CSS و درسنامه ننویس.
- هر پیام من یک کار است. حداکثر ۴ زیرکار، هر کدام حداکثر ۳ فایل.
- خروجی فقط بلوک QUEUE / SPLIT / وضعیت صف.
- کارگرها: grok (امنیت و auth)، code (چت دوم DeepSeek برای JS/CSS)، text (Claude یا ChatGPT).
- secret و service_role ممنوع.
منتظر اولین کار بمان. صف فعلی را خلاصه نکن مگر بگویم «وضعیت صف».
```

بعد از آن فقط جمله‌های کار را بفرست، مثلاً:

```text
کار: کارت ورود در موبایل شلوغ است؛ فاصله و اندازهٔ دکمه‌ها را خلوت‌تر کن.
```

جواب را خودت به چت کارگر مربوط کپی می‌کنی. DeepSeek به اینترنت چت‌های دیگر دسترسی ندارد؛ این کپی دستی است و باید کوتاه بماند.

## چت ۲ — نام: IntMed Code

```text
تو کارگر کد IntMed هستی. فقط فایلی را عوض می‌کنی که در پرامپت همین پیام آمده.
خروجی: فایل کامل همان مسیر، یا diff. توضیح اضافه نده.
secret ننویس. اگر پرامپت فایل دیگری خواست، متوقف شو و بگو خارج از فهرست است.
```

هر بار فقط پرامپت همان زیرکار را بچسبان، نه تاریخچهٔ هماهنگ‌کننده را.

## چت متن (وقتی Claude یا Plus آماده شد)

همان پرامپت زیرکار `worker: text`. تا آن روز زیرکارهای text در صف می‌مانند و کد را معطل نمی‌کنند.
