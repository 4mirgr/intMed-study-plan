# صف IntMed

انسان فقط زیر «صندوق» یک خط اضافه می‌کند و همان خط را به چت IntMed Coordinator می‌فرستد.
وضعیت‌ها: `inbox` | `split` | `doing` | `review` | `done` | `blocked`

## صندوق

خالی. کار جدید را این‌جا بنویس.

## صف تصمیم‌گرفته (شروع همین هفته)

| id | وضعیت | کارگر | فایل‌ها | کار |
|---|---|---|---|---|
| Q0 | done | انسان | همین بسته | فایل‌های صف روی شاخهٔ فعال commit شدند |
| Q1 | inbox | code | `docs/intmed.css` | خلوت‌کردن کارت ورود در عرض زیر ۶۰۰px: فاصلهٔ دکمه‌ها، اندازهٔ لمس حداقل ۴۴px، بدون تغییر منطق |
| Q2 | inbox | text | فقط خواندن `docs/content-protocol.md` | فهرست حداکثر ۱۰ topic ناقص. تا Claude یا Plus شروع نشود |
| Q3 | blocked | text | یک topic که Q2 معرفی کند | پیش‌نویس همان topic. شروع بعد از Q2 |
| Q4 | inbox | grok | `docs/js/intmed-dashboard.js` | فقط اگر باگ مشخص گزارش شد. تا آن موقع دست نزن |

## ترتیب ادامه

1. چت Coordinator و چت Code را با `docs/ai/DEEPSEEK_BOOT.md` بساز.
2. به Coordinator بگو: `کار Q1 را بشکن`.
3. پرامپت code را در چت Code بگذار. خروجی را به‌جای `docs/intmed.css` بگذار.
4. Q2 را تا Claude یا Plus نگه دار. کد و ظاهر را معطل محتوا نکن.
5. کار تازه فقط یک خط در صندوق است.

## یادداشت ادغام

اگر خروجی کارگر فایلی بیرون از ستون «فایل‌ها» را عوض کرد، commit نکن و به Coordinator بگو `خروجی خارج از فهرست بود`.
