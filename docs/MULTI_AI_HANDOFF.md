# IntMed — همکاری چند هوش مصنوعی

شاخهٔ فعال: `claude/quirky-ride-mavb6b`

انسان تنها کسی است که commit نهایی را تأیید می‌کند. هماهنگ‌کننده و کارگرها مستقیم push نمی‌کنند مگر خود انسان در همین چت اجازه بدهد.

## نقش‌ها (ثابت)

| نقش | مدل | کار مجاز | کار ممنوع |
|---|---|---|---|
| هماهنگ‌کننده | **DeepSeek** (چت جدا، فقط همین) | خواندن `docs/ai/QUEUE.md`، شکستن یک جمله به حداکثر ۴ زیرکار، نوشتن پرامپت کارگر | نوشتن کد محصول، درسنامه، CSS، یا خواندن کل ریپو |
| کارگر کد | DeepSeek چت دوم، یا Grok | JS/CSS داخل فهرست فایل همان زیرکار | محتوای پزشکی، secret |
| کارگر متن | Claude؛ از زمان آماده شدن Plus، ChatGPT | UX نوشتاری و پیش‌نویس درسنامه، حداکثر ۱ topic | بک‌اند و SQL |
| بازبین امنیت | Grok | لاگین، Supabase، Cloudflare، RLS | تولید انبوه محتوا |
| ادغام | انسان | تأیید خروجی و commit | — |

## مسیریابی

| اگر کار دربارهٔ این است | کارگر |
|---|---|
| قانون صف، Issue، handoff | هماهنگ‌کننده فقط صف را به‌روز می‌کند |
| لاگین، timeout، Supabase، Cloudflare، RLS | Grok |
| متن خطا، داشبورد، موبایل، پروفایل | Claude / ChatGPT |
| درسنامه، سوال، topic | Claude / ChatGPT، بعد بازبین انسانی |
| CSS، تم، انیمیشن سبک | کارگر کد |
| آزمون و برنامه‌ریزی | کارگر کد |
| `scripts/content_pipeline.py` | کارگر کد |

اگر دو حوزه درگیر است، زیرکارها را جدا کن. هر زیرکار حداکثر ۳ فایل.

## قانون توکن

هماهنگ‌کننده کد محصول نمی‌نویسد و تاریخچهٔ `docs/archive/` را نمی‌خواند. هر پرامپت کارگر باید این سقف را داشته باشد: هدف، ۳ فایل، معیار تمام‌شدن، و ممنوعیت secret. خروجی کارگر یا فایل کامل همان مسیر است یا diff همان فایل‌ها.

## وضعیت

- لاگین روی همراه اول با timeout واقعی درست شده است.
- متن‌های ورود دیگر VPN را راه‌حل اول نمی‌دانند (`docs/js/intmed-login.js` و `docs/js/intmed-backend.js`).
- صف زنده: `docs/ai/QUEUE.md`
- راه‌اندازی هماهنگ‌کننده: `docs/ai/DEEPSEEK_BOOT.md`
