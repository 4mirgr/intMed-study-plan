# IntMed – راهنمای همکاری چند هوش مصنوعی

این فایل را در ابتدای هر گفتگو با هر هوش مصنوعی بخوانید (یا خلاصه‌اش را بدهید).

## نقش انسان
- شما (صاحب پروژه) تنها کسی هستید که commit و push می‌کنید.
- هیچ هوش مصنوعی‌ای مستقیم به ریپو دسترسی نوشتن ندارد.
- خروجی هر AI را بررسی و در صورت تأیید ادغام کنید.

## نقشه حوزه‌ها و مسیریابی خودکار

هر کار را بر اساس کلمات کلیدی و نوع تغییر به حوزه زیر نسبت دهید:

| حوزه | کلمات کلیدی تشخیص | فایل‌های اصلی مجاز | AI پیشنهادی (اولویت) |
|------|-------------------|---------------------|----------------------|
| **ساختار و قوانین** | handoff, قانون, ساختار, AGENTS, معماری, تقسیم کار | `AGENTS.md`, `docs/MULTI_AI_HANDOFF.md`, `docs/architecture.md` | Grok |
| **بک‌اند / لاگین / امنیت** | لاگین, timeout, supabase, cloudflare, auth, RLS, session, proxy | `docs/js/intmed-backend.js`, `docs/js/intmed-login.js`, `backend/cloudflare/`, `backend/supabase/` | Grok → DeepSeek |
| **UX و مسائل کاربر** | پیام خطا, موبایل, داشبورد, پروفایل, جریان کاربر, UX, UI متنی | `docs/js/intmed-dashboard.js`, `docs/js/intmed-login.js`, `docs/index.html` (فقط بخش‌های متنی) | Claude / ChatGPT → Grok (بازبین) |
| **محتوای آموزشی** | درسنامه, topic, سوال, درس, content, taxonomy, فصل | `content/`, `docs/content-protocol.md`, `scripts/content_pipeline.py` | Claude / DeepSeek → بازبین انسانی |
| **جلوه‌های بصری** | CSS, تم, انیمیشن, رنگ, dark mode, night-shift, آیکون | `docs/intmed.css`, `docs/js/intmed-theme.js` | DeepSeek / ChatGPT |
| **امتحان و برنامه‌ریزی** | exam, آزمون, دور, برنامه‌ریزی مطالعه | `docs/js/intmed-exams.js`, `docs/exams-and-planning.md` | DeepSeek / Claude |
| **اسکریپت و ابزار** | pipeline, validate, build, script | `scripts/` | DeepSeek / Grok |

**قانون مسیریابی:**  
اگر کار بین دو حوزه بود، اولویت با حوزه‌ای است که **تغییر فایل بیشتری** ایجاد می‌کند. در صورت ابهام، اول از Grok بپرسید.

## قوانین اجباری (همه AIها)

1. فقط فایل‌های حوزه خود را پیشنهاد تغییر دهید.
2. هیچ `service_role`، توکن، رمز، یا secret واقعی در کد یا پاسخ ننویسید.
3. خروجی را به یکی از این شکل‌ها بدهید:
   - فایل کامل آماده جایگزینی
   - یا diff واضح با ذکر مسیر فایل
4. برای کارهای محتوایی: قبل و بعد `python3 scripts/content_pipeline.py validate` و در پایان `build` را پیشنهاد دهید.
5. کارهای بزرگ را به تکه‌های کوچک بشکنید.
6. از بازنویسی کامل فایل‌های بزرگ بدون دلیل خودداری کنید.

## وضعیت فعلی پروژه (این بخش را انسان به‌روز می‌کند)

- شاخه فعال: `claude/quirky-ride-mavb6b`
- آخرین کار مهم: اصلاح timeout واقعی در `intmed-backend.js` (لاگین روی شبکه‌های محدود)
- کارهای در جریان: تعریف سیستم همکاری چند AI
- اولویت‌های نزدیک:
  1. نهایی کردن همین سند و قوانین
  2. بهبود پیام‌ها و جریان UX لاگین/خطا
  3. تسریع تولید محتوای آموزشی (topicهای ناقص)
  4. بهبودهای بصری سبک (تم و CSS)
