## مهم‌ترین اقدام برای جلوگیری از برداشت انبوه محتوا

در سایت فعلی فایل‌ها روی میزبانی عمومی هستند. خصوصی‌کردن مخزن فقط دسترسی به خود مخزن را محدود می‌کند؛
فایل‌های منتشرشدهٔ سایت همچنان قابل دانلود می‌مانند. مسیر اصولی این است:

1. پوستهٔ سایت عمومی بماند؛ درسنامه، JSON، تصویر و ماژولِ محافظت‌شده در فضای خصوصی قرار بگیرد.
2. سرور پیش از تحویل محتوا، ورود و تأیید مدیر برای همان حساب را بررسی کند؛ لینک‌ها کوتاه‌عمر باشند.
3. تعداد درخواست‌ها محدود و دسترسی غیرعادی ثبت شود. برای آزمون رسمی، کلید پاسخ نیز باید سمت سرور بماند.
4. واترمارک شخصی می‌تواند بازنشر را دشوارتر کند، ولی کاربر مجاز همچنان می‌تواند عکس صفحه بگیرد یا محتوا را کپی کند.

بستن راست‌کلیک یا مخفی‌کردن JavaScript حفاظت واقعی ایجاد نمی‌کند و ممکن است قابلیت هایلایت را مختل کند.
انتقال محتوا به فضای خصوصی هنوز انجام نشده است؛ پیش از انتقال، نباید مسیرها یا مخزن را طوری تغییر دهیم که سایت قطع شود.

## پیش از اپ اندروید

ابتدا حفاظت محتوا، تأیید دسترسی در سرور، ورود دومرحله‌ای مدیر، نسخهٔ پشتیبان قابل بازیابی و بررسی امنیتی مستقل
تکمیل شود. اپ باید از همین API امن استفاده کند؛ هیچ کلید service_role، توکن بات یا کلید ارسال ایمیل نباید در APK باشد.
فایل‌هایی که داخل APK بسته‌بندی می‌شوند قابل استخراج‌اند؛ ساخت اپ به‌تنهایی محتوا را خصوصی نمی‌کند.
